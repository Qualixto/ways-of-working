# CLAUDE.md

Guidance for AI coding agents working in this repository.

## Project

A public handbook built with MkDocs Material. Pages under `docs/` are **generated** from notes in an Obsidian vault by `scripts/sync.py`; the vault is the source of truth.

- Don't edit generated pages (they start with a "Generated by scripts/sync.py" comment). Change the source note and run `uv run invoke sync --vault <path>`.
- Hand-written files are listed in `HAND_WRITTEN` in `scripts/sync.py` (`in-practice.md`, `assets/`, `stylesheets/`); sync never touches them.
- New notes need a `nav` entry in `mkdocs.yml`; the strict build warns about pages missing from it.
- Never publish client names, client examples or anything from outside the ways-of-working folder.

## Commands

```sh
uv run invoke lint    # ruff and mypy --strict on the sync script and tests
uv run invoke test    # conversion tests
uv run invoke build   # mkdocs build --strict: broken links fail
uv run invoke serve   # live preview
```

## Conventions

- Branch as `<type>/<issue>-<short-description>`; start from an issue.
- Commits are `<type>: <description>` with types `feat`, `fix`, `refactor`, `test`, `docs`, `chore`, `perf`.
- Never add AI attribution (`Co-Authored-By` trailers or "Generated with" footers) to commits, pull requests, issues or comments.
- Comments explain *why*, not *what*.
